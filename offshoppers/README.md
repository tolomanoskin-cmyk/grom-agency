!! READ ME !! 

Bonjour et bienvenue sur le projet SHOPPERS. Nous avons le plaisir de vous présenter la Web App codé par
le créateur du projet. 

Afin de bien mener l'analyse du site, il est nécéssaire d'avoir un éditeur de texte (Studio Visual Code, 
Sublime Text, ou autre...). 

Vous retrouverez dans le dossier SITE : 

- Les deux corps HTML des pages : d'accueil & contact
- Le SCSS ainsi que le main.min.css : le fichier qui permet d'alléger le code au maximum 
- Le dossier JS qui est composé de du fichier jQuery : permet une animation spécifique sur le site 
- Le dossier "fonts" qui regroupe toutes les polices et ses composants utilisés 
- Le dossier "photo" qui regroupe toutes les photos, icônes, le  logo etc...
